## Current limits

The rolls and defensive clips are original reconstructions, not extracted DS3 data. Blade contact follows the avatar-adapted authored path, with sampled segments and expanded body bounding boxes; it is not exact mesh collision. Clothing, hair and accessories do not enlarge hurtboxes, and arbitrary wardrobe/body clearance is not guaranteed by the visual body-box solver. Some tested proportions require substantial shoulder correction; their silhouettes still need review. Two-client tests use controlled contact fixtures; moving duels, jitter/loss, published animations and persistent settings round trips remain untested. There is no network rewind. Root-jump sweep protection does not certify movement anti-cheat. Default locomotion still needs dedicated combat clips. See TEST_REPORT.md and AVATAR_COMPATIBILITY.md.

## Build

From the repository root, run Blender 5.2 with `-b --python combat/tools/author_blender.py`, then run `python combat/tools/package_rbxmx.py`. The Blender authoring script reads the existing R15 rig as a donor and writes only under `combat/`. Do not edit the old map to build assets. In Studio, run `combat/tools/import_studio.luau` in Edit mode with a localhost HTTP server rooted at `combat/`, or inspect `CombatFoundation_Import.rbxmx` as a portable package. The XML package has not yet been independently reimported; use the verified import script for testing.

Package inventory: ten shared modules, five server scripts/modules, three client LocalScripts and twelve real animation sources. Install the complete shared/server set, including `BladeTrajectory` and `CombatObserver`; a missing source or unsupported rig leaves sword contact unavailable rather than enabling a generic fallback hitbox.

Defaults: Mouse1 R1, Mouse2 R2, Space roll, F hold block, E parry, Shift hold sprint, Q lock-on. Use «Управление» to rebind or reset them. Duplicate assignments and WASD conflicts are rejected. Menus, chat focus and window focus loss release held actions. WASD chooses a camera-relative roll direction, checked by the server.
