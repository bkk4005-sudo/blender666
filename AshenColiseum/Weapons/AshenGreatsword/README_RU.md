# Пепельная клятва / Ashen Oath

Оригинальный двуручный меч и 34 полнотелые анимации для стандартного скелета R15. Из Dark Souls 3 взят принцип тяжёлого движения: подготовка, ускорение, инерция и восстановление. Модель, геометрический орнамент и движения созданы заново; ресурсы или анимации игры не извлекались.

## Посмотреть

- `AshenOath_R15.blend` — основной файл с мечом, R15, демонстрационным манекеном и всеми Actions. Внутри упакованы четыре текстуры 2048 × 2048.
- `Open-Blender.ps1` открывает последовательность анимаций. Нажмите Space; названия клипов отмечены на Timeline.
- `Open-Blender.ps1 -Clip Light_01` — открыть отдельную анимацию с синхронным движением меча. Доступны все имена ниже. `-Clip Showcase` возвращает демонстрацию.
- `previews/03_combat_demo.mp4` — 30 кадров/с: стойка, три удара и заряженный удар. `03_combat_demo.gif` — уменьшенная версия.
- `previews/02_sword_detail.png` — крупный вид меча; `04_motion_sheet.jpg` — основные фазы.

В редакторе включён быстрый Solid. Для материалов и света используйте Rendered или F12. Манекен нужен для оценки движения и хвата; это не финальный дизайн игрового персонажа.

## Набор клипов

| Назначение | Actions |
|---|---|
| Стойка и передвижение | Idle, WalkForward, WalkBackward, StrafeLeft, StrafeRight, RunForward |
| Оружие в руках | Equip, Unequip |
| Основные атаки | Light_01, Light_02, Light_03 |
| Заряжаемая атака | Heavy_Charge, Heavy_Hold, Heavy_Release |
| Другие атаки | Running_Attack, Thrust, Riposte |
| Защита | Guard_Enter, Guard_Loop, Guard_Exit, Guard_Impact, Guard_Break, Parry |
| Реакции на попадание | Hit_Front, Hit_Back, Hit_Left, Hit_Right |
| Уклонения шагом | Dodge_Forward, Dodge_Backward, Dodge_Left, Dodge_Right |
| Воздух и приземление | Jump, Fall, Land |

Основные удары занимают 1,40 / 1,48 / 1,88 секунды, включая восстановление. Тяжёлый удар состоит из подъёма 1,10 с, удержания и выпуска около 1,53 с. Это исходные тайминги для настройки игры, а не уже проверенный PvP-баланс. Equip/Unequip показывают подведение оружия к хвату и отведение к боку; отдельные ножны не моделировались.

## Почему меч ощущается тяжёлым

У замаха есть отдельная подготовка; активная часть заметно быстрее. Корпус и таз разворачиваются, колени принимают нагрузку, клинок проходит за точку удара. Тяжёлый вертикальный удар заканчивается низко и возвращается в стойку медленно. Ноги у основных атак стоят на опоре. Положение обеих рук рассчитано от одной рукояти; анимации запечены покадрово, поэтому для проигрывания экспортированных клипов Blender IK не нужен.

В самой игре ощущение веса также зависит от звука, реакции противника, камеры и момента контакта. Эти игровые системы в данный пакет не входят.

## Структура и экспорт

- `exports/AshenOath_Greatsword.fbx` — отдельный меч с UV и материалами; начало координат находится в центре правого хвата.
- `exports/animations/*.fbx` — каждый клип отдельно, со скелетом и демонстрационными мешами. Меч экспортируется отдельно и крепится к правой руке в игре.
- `textures` — Color, Metalness, Roughness, Normal в PNG, 2048 × 2048.
- `animation_manifest.json` и `CombatTimings.luau` — длительности, признаки циклов, метки и рекомендуемое перемещение.
- `build_weapon.py`, `motions.py`, `bake_materials.py` — воспроизводимые исходники. Сборка перезаписывает blend и экспорты; ручные изменения сохраняйте отдельной версией.

У каждой Action тела есть парная `PROP__имя` для предпросмотра меча. Переключать только Action тела недостаточно: оружие должно получить соответствующую PROP Action. `select_clip.py` делает это автоматически. В игре PROP Action не нужна при корректном жёстком креплении меча к правой руке.

Локальная ось клинка в Blender — +Z. Правый хват: `(0, 0, 0)`, левый: `(0, 0, -0.53)`, начало рабочей части: `(0, 0, 0.56)`, кончик: `(0, 0, 3.55)`. Общая длина модели около 4,71 единицы. Для данного скелета матрица Sword относительно кости RightHand имеет перенос `(0, 0.20, 0)` и поворот 180° вокруг X; это преобразование кости Blender, не готовое значение `Tool.Grip` стандартного Roblox Part.

Все клипы сделаны на месте: игровое перемещение, прыжок и уклонение должен задавать контроллер Roblox. `SuggestedTravel` — предложение для настройки этого перемещения; оно не происходит само при проигрывании анимации.

## Подключение в Studio

1. Создайте тестового персонажа R15. Импортируйте клип в Animation Editor через Import → From File и проверьте вариант Imported Rig для исходной позы. Сначала проверьте Idle и Light_01.
2. Импортируйте меч отдельно через Import 3D, согласуйте его масштаб с персонажем и закрепите в правой руке. Проверьте положение левой кисти в стойке, замахе и конце удара.
3. Для SurfaceAppearance используйте четыре PNG из `textures`. Наличие изображений в FBX не заменяет проверку всех PBR-каналов в Studio.
4. Выставьте Loop для циклических клипов по manifest. Для полнотелых атак используйте приоритет Action, для перемещения — Movement, для стойки — Idle.
5. Добавьте события из `Markers` в Animation Editor. Маркеры Blender не считаются автоматически перенесёнными через FBX. Например, Light_01 имеет ActiveStart 0,52 с и ActiveEnd 0,75 с.
6. Опубликуйте анимации от владельца Experience и подключите полученные IDs в контроллере игры.

Использован официальный технический скелет R15 с его именами и иерархией. Другие пропорции R15 могут изменить двуручный хват, поэтому нужна проверка на выбранном игровом аватаре. Импорт и проигрывание в Roblox Studio в этой работе не выполнялись; экспорт не выдаётся за опубликованные Animation IDs.

## Проверки

`validation.json` содержит данные сборки. `export_checks.json` — фактическую проверку всех 34 FBX обратным импортом в Blender, швов циклов, правого хвата и неподвижности стоп у основных атак. `verify_exports.py` завершает работу с ошибкой при нарушении допусков. Рендеры проверены по ключевым фазам комбо и тяжёлого удара.

Источники технической совместимости: [официальный скелет R15](https://create.roblox.com/docs/art/accessories/creating/armature-setup), [импорт FBX-анимаций](https://create.roblox.com/docs/avatar/animation-packs), [перенос Blender → Studio](https://create.roblox.com/docs/art/blender).
