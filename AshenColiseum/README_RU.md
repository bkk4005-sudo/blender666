# Колизей пепельной короны

Новая авторская сцена для игры с дуэлями 1 на 1. Геометрия создана с нуля; сцены, модели и текстуры Eclipse Sanctum не использованы.

## Открыть

`AshenColiseum.blend` — основной редактируемый файл. Из PowerShell запустите `./Open-Blender.ps1` в этой папке. Скрипт находит установленный Blender автоматически. Если он находится в нестандартном месте, задайте полный путь через переменную окружения `BLENDER_EXECUTABLE`.

Для открытия меча и анимаций используйте `Weapons/AshenGreatsword/Open-Blender.ps1`; пример: `./Weapons/AshenGreatsword/Open-Blender.ps1 -Clip Light_01`. Путь к исполняемому файлу для пакетной работы можно получить командой `$blender = & ./Get-BlenderExecutable.ps1`.

В рабочем окне включён облегчённый режим Solid с цветами материалов. Чтобы видеть окончательные материалы и свет, включите Rendered или нажмите F12. В сцене сохранены четыре камеры: общий вид, интерьер, дуэльный двор и план сверху. Готовые PNG находятся в `renders`.

## Архитектура

- Центральный колизей: два яруса настоящих арочных проёмов, пять рядов трибун, четыре ворот, каменные стражи, знамена и кольцевая каменная мозаика с латунной розой направлений.
- Восток — двор кузни: очаг, массивный дымоход, тёплый камень и жаровни.
- Север — лунное святилище: скульптурное кольцо, светящийся минерал и два небольших водоёма.
- Запад — заросший двор: кипарисы, мох и колоннада.
- Юг — двор павших королей: памятник стражу, обелиски, синие знамена и обломки у периметра.
- Четыре мостика с парапетами и фонарями соединяют площадки с осевыми входами колизея. Каменные основания опускаются к нижнему скальному ландшафту.

Декор расположен по краям дуэльных площадок. В каждой отмечены две противоположные точки старта, свободный круг боя и зрительские скамьи. Маркеры старта — служебные Empty в коллекции `12 / Gameplay layout / guides only`, они не видны в рендере.

Сцена использует условный масштаб: 1 единица Blender = 1 предполагаемый stud. Центральное боевое поле имеет диаметр около 50 единиц, малые площадки — около 26, свободная зона боя — 21. Окончательные размеры и дистанции рывка следует согласовать с механикой будущей игры. Это редактируемая художественная сцена; импорт в Studio, коллизии, серверная логика дуэлей и проверка камеры в игре пока не выполнялись.

## Устройство файла

Коллекции разделены по локациям. Внутри каждой геометрия сгруппирована по материалам; отдельные камни можно выделять как связанные острова в Edit Mode. Фаски сохранены модификаторами. Материалы используют процедурный рисунок камня и не требуют внешних изображений. Перед переносом этих материалов в Roblox потребуется запекание текстур или подбор материалов Studio.

`build_scene.py` воспроизводит сцену, `render_views.py` создаёт дополнительные виды. Повторный запуск сборки перезаписывает основной blend, поэтому ручные правки сохраняйте отдельной версией. `build_report.json` содержит фактический размер геометрии; `layout_check.json` — проверку прямых проходов к площадкам на высоте корпуса персонажа. Эта проверка не заменяет игровой тест.

Техническая справка для скрипта: [Compositor API Blender 5](https://developer.blender.org/docs/release_notes/5.0/migration/compositor_migration/).
